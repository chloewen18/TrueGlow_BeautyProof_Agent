# 志愿者采集启动包

状态：采集入口已可用；招募尚待团队实际开展。以下数量为计划，不是已完成指标。

## 第一轮计划

目标：先邀请10名已成年且自愿参加的同学，每人提供同条件不同帧、微小光照变化、真实上妆前后中的1至3对。另由团队在获同意的素材上制作仅JPEG压缩/缩放的对照，保存派生关系。

成员5负责安排本机采集并保管撤回流程；成员2核查来源与压缩记录；成员3与另一名成员独立复核标签；成员1接入真实失败案例；成员4写清图像与文案可支持的结论范围。

入口：TrueGlow → 评测工作台 → 志愿者采集。当前本机链接不能发给异地同学直接使用，可先现场通过本机提交；远程采集需先完成私有认证部署，不建议把含人脸的未加固原型直接公开。

## 可发群内的招募文案

我们准备为TrueGlow做一轮真实场景内部评测，想邀请已成年、愿意参加的同学提供本人前后对比照片，主要测试“没有美颜但有光线、压缩或真实上妆变化时，系统会不会误报”。参加完全自愿，不评价长相，也不做身份识别。

图片仅用于本团队内部评测，不用于训练或公开展示；提交时会明确说明保存期限和用途，也可以凭撤回码删除。请不要直接往群里发照片，有意参加的同学先联系我安排采集。没参加也完全没关系。

## 标签与评测纪律

- 同意前不收件，不上传他人人脸，不收未成年人素材，不收姓名/联系方式/GPS。
- 记录本人声明的拍摄条件、实际滤镜及编辑操作；自述不自动当成审核真值。
- 所有样本初始为待双人复核；有分歧保留unknown，不强行填磨皮或美白。
- 同一人及其所有压缩派生图片进入同一个分组；在评测之前冻结阈值和数据划分。
- 曝光差异、修饰操作、原始/修饰、产品因果是不同标签；不混用。
- 团队在30天内处理删除，到期样本会在采集服务下次访问时清理；设备关闭不会后台自动删除。无备份和训练副本，撤回时删除该提交的图像和记录。
- 采集数、审核数、可用评测数分别记录；计划数量不得当作已完成数量。
