# Claim-Evidence Benchmark 标注指南

## 字段说明

| 字段 | 说明 |
|------|------|
| `claim` | 产品/博主宣称的美妆功效，如持妆、遮瑕、毛孔隐形等 |
| `evidence_text` | 帖子/广告中的文字描述 |
| `evidence_image_meta` | 图像层面的证据摘要（是否磨皮、是否有对比图、时间维度等） |
| `groundtruth_label` | `SUPPORTED` / `INSUFFICIENT` / `CONFOUNDED` / `CONTRADICTED` |
| `reason` | 人工标注的推理理由 |

## 四类标签判定标准

### 1. SUPPORTED — 证据充分
- 图文证据能够支撑该美妆宣称
- 图像无修图干扰或修图不影响核心判断
- 时间/对比维度完整

**示例**：宣称“7天不泛红”，提供连续7天无修图对比 + 文字记录。

### 2. INSUFFICIENT — 证据缺失
- 宣称需要特定维度（时间、对比图）但素材不足
- 仅有文字或单张图片，无法验证效果

**示例**：宣称“12h持妆”，只有刚上妆照片。

### 3. CONFOUNDED — 混淆变量（最核心）
- 观察到的美妆效果可能来自数字修图，而非化妆品本身
- 判断公式：**效果可见 + 检测到磨皮/平滑 → 不能归为化妆品功效**

**示例**：宣称“粉底液隐形毛孔”，after图检测到高强度皮肤平滑。

### 4. CONTRADICTED — 图文矛盾
- 图像证据或文字证据与宣称直接冲突

**示例**：宣称“自然无妆感”，但图像明显经过磨皮/液化。

## 标注 checklist

1. [ ] `claim` 是真实存在的美妆功效宣称
2. [ ] `evidence_text` 与 `evidence_image_meta` 不重复、互补
3. [ ] 标签与 `reason` 100% 逻辑对应
4. [ ] 无重复案例、无 AI 逻辑错误
5. [ ] `CONFOUNDED` 案例必须明确写出“检测到磨皮/平滑”
6. [ ] `INSUFFICIENT` 案例必须明确写出缺失的维度

## 每人产出建议

- 每人 20 条，共 5 人 = 100 条
- 建议分布：`SUPPORTED` 25 条、`INSUFFICIENT` 25 条、`CONFOUNDED` 35 条、`CONTRADICTED` 15 条
- 覆盖维度：持妆、遮瑕、毛孔、提亮、敏感肌、控油、防晒、妆感自然
