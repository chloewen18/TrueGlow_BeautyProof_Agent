# 成员 3 最终对接包

当前接口版本：`1.1.0`。本版已统一 `comparison_reliability = Low / Medium / High / Unknown`，并在单图与配对输出中增加 `mode`、`engine`、`provenance`。

## 定位

这不是新的 Main Agent，而是供成员 1 的 Main Agent 调用的 **Beauty Effect Attribution Tool（底妆修饰与妆效归因 Tool）**。

内部路由：

- Stage 1 / FFHQR：通用专业修图二分类。
- Stage 2 / RetouchingFFHQ + rehearsal：美白、磨皮、瘦脸、放大眼睛辅助信号。
- Stage 3 / PPR10K：Before/After 曝光、白平衡和色调参数差与妆效归因可靠性。

## 最快使用

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements-core.txt
python example.py
```

无需 API 依赖的 CLI 调用：

```bash
python cli.py single --image image.jpg
python cli.py pair --before before.jpg --after after.jpg --mask mask.png
```

API 服务：

```bash
pip install -r requirements-api.txt
uvicorn api:app --host 0.0.0.0 --port 8003
```

## 接入 Main Agent

成员 1 可以选择：

1. 将整个 `beautyproof_tool` 目录复制到后端，直接调用 `BeautyProofTool`。
2. 独立运行 `api.py`，Main Agent 通过 HTTP 调用。

推荐第二种，因为模型依赖与 Main Agent 解耦，也便于日志和超时控制。

## 系统边界

- 只输出证据信号，不判定创作者意图。
- Stage 2 操作概率尚未完成社交媒体跨域校准。
- Stage 3 change probability 对真实负样本的校准不足，Main Agent 应优先使用连续参数差与透明规则。
- 无 mask 可运行，但前景/背景统计可靠性会下降。
