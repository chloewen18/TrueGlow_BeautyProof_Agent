# BeautyProof 修复训练最终报告 v1

## 结论摘要

本轮完成了抗遗忘混合训练、PPR10K 特征重建、零变化负样本校正和第四阶段重测。修复取得了两项明显改善，但也证明“用一个共享模型同时包办所有域”暂时不可靠。

- FFHQR 通用修图 ROC-AUC 从 56.22% 恢复到 86.23%，F1 从 19.73% 恢复到 64.40%。
- 第三阶段对完全相同图片的三类误报率均降为 0%。
- RetouchingFFHQ 四类操作检测基本保住，但通用二分类 F1 从 90.76% 下降到 87.15%。
- PPR10K 上的第二阶段跨域表现没有修好；Source 误报率由 27.54% 升至 35.85%，After 分数高于 Before 的配对仅 31.66%。
- 第三阶段学会了区分“完全相同”与“真实配对”，但在 PPR10K 真实少数负样本上的 FPR 仍接近 100%，说明还没有学会识别“两张不同图但条件未显著变化”。

## 第二阶段修复结果

| 指标 | 修复前 | 修复后 | 变化 |
|---|---:|---:|---:|
| FFHQR F1 | 19.73% | 64.40% | +44.67 个百分点 |
| FFHQR ROC-AUC | 56.22% | 86.23% | +30.01 个百分点 |
| FFHQR FPR | 6.11% | 6.01% | 基本不变 |
| RetouchingFFHQ 二分类 F1 | 90.76% | 87.15% | -3.61 个百分点 |
| 美白 F1 | 59.31% | 60.67% | +1.36 个百分点 |
| 磨皮 F1 | 96.39% | 96.90% | +0.51 个百分点 |
| 瘦脸 F1 | 94.80% | 94.95% | +0.15 个百分点 |
| 放大眼睛 F1 | 90.72% | 90.98% | +0.26 个百分点 |

抗遗忘训练有效，但修复后 FFHQR 仍未达到第一阶段独立模型的 F1 85.08% / ROC-AUC 94.77%。因此不建议用修复后第二阶段模型取代第一阶段通用修图 Tool。

## 第三阶段修复结果

| 零变化控制组 | 修复前 FPR | 修复后 FPR |
|---|---:|---:|
| 曝光 | 0.61% | 0% |
| 白平衡 | 0.29% | 0% |
| 色调 | 57.03% | 0% |

在真实 PPR10K Source/Target 对中，三类任务的 F1 分别为 94.49%、94.22% 和 99.53%。但这些 F1 受到极度类别不平衡影响：真实负样本上的 FPR 分别为 98.80%、100% 和 100%。因此不应宣传高 F1，应优先补充非同图的困难负样本。

参数回归能力仍可作为连续证据：曝光 MAE 0.244 EV，色温 MAE 353 K，Tint MAE 5.91。产品层应展示参数差与不确定性，而不应单独使用 0.5 阈值给出定性定罪。

## 建议的最终 Tool 路由

1. **FFHQR 第一阶段模型**：负责通用专业修图二分类。
2. **修复后 RetouchingFFHQ 第二阶段模型**：只负责美白、磨皮、瘦脸和放大眼睛细粒度信号，并保留“未跨域校准”警告。
3. **PPR10K 第三阶段模型**：优先输出曝光、白平衡和色调参数差；暂不将 change probability 直接转成“有/无造假”。
4. **Main Agent**：融合三个 Tool 的证据，输出“归因可靠性 Low/Medium/High”，不输出虚假精确的产品贡献百分比。

## 下一轮数据优先级

如果继续提升，最缺的不是更多“有修图”数据，而是以下困难负样本：

- 同一人、不同帧，但曝光/白平衡/色调实际未显著改变；
- 只经过 JPEG 压缩、截图、缩放、平台二次编码的图片对；
- 光线微变但未使用美颜的真实手机连拍；
- 有真实底妆差异，但未使用滤镜或磨皮的 Before/After。

## 边界

所有测试阈值均由验证集确定，未在测试集上调参。PPR10K 是专业修图数据，不是虚假宣传意图数据；本系统只能给出证据和风险提示，不能单独证明创作者造假。
