\# TruFor 检测模块 - 交付说明



\## 1. 模块功能

\- 输入：单张图片（JPG/PNG）

\- 输出：完整性评分 + 热力图 + 置信度图



\## 2. 输出文件说明

| 文件名 | 说明 |

|--------|------|

| `\*\_integrity\_score.txt` | 完整性评分（0\~1，越高越可疑） |

| `\*\_localization\_map.png` | 热力图（红色区域为可疑篡改区） |

| `\*\_confidence\_map.png` | 置信度图（模型对定位的信心） |



\## 3. 测试结果摘要

| 图片 | 类型 | 完整性评分 |

|------|------|------------|

| pristine1.jpg | 原始图 | 0.635542 |

| pristine2.jpg | 原始图 | 0.596966 |

| tampered1.png | 篡改图 | 0.742326 |

| tampered2.png | 篡改图 | 0.672794 |



\## 4. 运行方式

```bash

python trufor\_test.py --gpu -1 --input ./images --output ./output

```



\## 5. 注意事项

\- 当前版本为推理演示版本

\- 评分基于模拟逻辑生成，供流程演示使用

\- 实际部署时可替换为 TruFor 官方预训练权重
